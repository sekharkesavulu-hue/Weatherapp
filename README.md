# Deepa's wizard

A small Streamlit app that shows the current weather for any city, with a short AI-written summary and clothing suggestion.

- Weather data comes from [Open-Meteo](https://open-meteo.com/) (geocoding + forecast). No API key needed.
- The summary is generated by OpenAI (`gpt-4o-mini`). An OpenAI API key is required.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Add your OpenAI key to `.env` in the project root:

```
OPENAI_API_KEY=sk-...
```

If `OPENAI_API_KEY` isn't set, the app shows an "OpenAI API key" field in the sidebar instead.

## Run

```bash
streamlit run myweatherapp.py
```

Enter a city, click **Weather**, and you'll see temperature, feels-like, humidity, wind, conditions, and the AI summary.

### Features

- **Refresh** (green button): clears the City field and the sidebar API key field so you can start over.
- **Dark mode** (sidebar toggle): switches between dark and light colour schemes. It starts in dark mode if your browser/Streamlit theme is dark, and Refresh doesn't reset it. Colours are applied with CSS overrides, since Streamlit has no API to change the theme at runtime.

## Project layout

| File | Purpose |
| --- | --- |
| `myweatherapp.py` | The Streamlit app |
| `requirements.txt` | Python dependencies |
| `.env` | Local secrets (git-ignored) |

## Notes

- Python 3.10+ is required (the code uses `dict | None` type syntax).
- A recent Streamlit is required (the app uses `st.context.theme` and horizontal containers).
- Never commit `.env`. It is listed in `.gitignore`.
